# DOCS

PURPOSE
Architecture and product documentation that doesn't belong in code comments or module CLAUDE.md files (e.g. ADRs, GST/compliance research notes with their official sources, API design decisions spanning multiple modules).

STATUS
Empty. Do not pre-create documents speculatively — add a doc here when a decision or piece of research is significant enough to need a durable record beyond the relevant module's CLAUDE.md.

RULES
- Any GST/e-Invoice/e-Way Bill/tax research notes must cite the official government source and the date it was checked (these requirements change).
- Prefer updating the relevant module's CLAUDE.md for anything module-scoped; use this directory only for cross-module or historical-decision content.
